# Journal 2026-10-22 — Affichage des quartiers sur la carte

## Problème de départ

Les noms de quartiers (fokontany) n'apparaissaient pas sur la carte Leaflet,
ni sur mobile ni sur desktop. Ce n'était pas un bug mobile : la fonctionnalité
n'était tout simplement pas implémentée.

Causes identifiées :
- Aucun code pour afficher des quartiers dans `map.js`
- Les tuiles Carto `voyager_only_labels` n'incluent pas les fokontany de Madagascar
- Aucune table `quartiers` en base, aucun endpoint API

---

## Ce qu'on a fait

### 1. Migration de l'image Docker PostgreSQL

L'image `postgres:17-alpine` ne supporte pas PostGIS.
Remplacement par `postgis/postgis:16-3.4` via un nouveau `docker-compose.yml`.

- Backup de la base : `~/Desktop/tm_location_backup.sql`
- Nouveau fichier : `docker-compose.yml` à la racine du projet
- Commande de démarrage : `docker compose up -d`

### 2. Activation de PostGIS

```sql
CREATE EXTENSION IF NOT EXISTS postgis;
-- Résultat : PostGIS 3.4 USE_GEOS=1 USE_PROJ=1 USE_STATS=1
```

### 3. Installation de osm2pgsql

```bash
brew install osm2pgsql
# Version installée : 2.3.1
```

### 4. Import des données OSM Madagascar

Source : Geofabrik (`madagascar-latest.osm.pbf`, ~50 MB)
Fichier de style : `scripts/import_quartiers.lua`
Filtre : `admin_level=8` (communes) + `admin_level=10` (fokontany)

Résultat : **1 242 entrées** importées (625 fokontany, 617 communes)

```bash
osm2pgsql -d postgresql://postgres:dev@localhost:5432/tm_location \
  --slim -O flex -S scripts/import_quartiers.lua \
  ~/Downloads/madagascar-latest.osm.pbf
```

### 5. Migration Alembic — ajout colonne UUID

Fichier : `alembic/versions/b1c2d3e4f5a6_quartiers_add_uuid_pk.py`

Ajout d'une colonne `id UUID` primary key sur la table `quartiers`
existante (les 1 242 lignes importées ont reçu un UUID automatiquement).

### 6. Modèle SQLAlchemy

Fichier : `app/models/quartier.py`
Colonnes : `id` (UUID PK), `osm_id`, `nom`, `nom_court`, `type`, `actif`, `geom`

### 7. Endpoint API

Fichier : `app/client/itineraire/routes.py`
Route : `GET /api/quartiers?min_lon=&min_lat=&max_lon=&max_lat=`
Retourne un GeoJSON FeatureCollection filtré par bbox, limité à 200 features.

### 8. Overlay Leaflet

Fichier : `static/js/itineraire/map.js`
- Fetch `/api/quartiers` sur `map.on('moveend')` et au chargement
- Apparition uniquement à partir du zoom 13
- Labels permanents avec style `.quartier-label` (blanc, text-shadow noir)

Fichier : `static/css/itineraire.css`
- Ajout du style `.quartier-label`

## Problème découvert : couverture OSM incomplète

Les fokontany du **centre-ville d'Antananarivo** (Analakely, Ivandry,
Faravohitra, etc.) ne sont pas cartographiés dans OSM au niveau admin_level=10.

Solution temporaire : vue initiale de la carte déplacée vers `-18.94, 47.49`
(zoom 13) pour afficher les fokontany disponibles en périphérie.
